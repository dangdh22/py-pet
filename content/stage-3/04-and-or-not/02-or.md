Robo được nghỉ học vào thứ bảy **hoặc** chủ nhật. Để nối 2 điều kiện theo kiểu "hoặc", con dùng từ **or**:

```python run
thu = "chủ nhật"
if thu == "thứ bảy" or thu == "chủ nhật":
    print("Hôm nay Robo được nghỉ")
else:
    print("Hôm nay Robo đi học")
```

thu == "thứ bảy" là False, nhưng thu == "chủ nhật" là True. Chỉ cần 1 bên đúng, nên Python in ra Hôm nay Robo được nghỉ.
---
Điều kiện có or là True khi **ít nhất 1 bên True**, kể cả khi cả 2 bên cùng True. Điều kiện chỉ là False khi **cả 2 bên đều False**:

```python run
print(True or True)
print(True or False)
print(False or True)
print(False or False)
```

Python in ra 3 lần True, rồi False. Con so sánh với and: and cần cả 2 bên đúng, còn or chỉ cần 1 bên đúng.
---
Muốn hỏi "so bằng 1 hoặc 2", nhiều bạn viết giống như khi nói: `so == 1 or 2`. Python không báo lỗi, nhưng kết quả sai:

```python run
so = 5
if so == 1 or 2:
    print("Số 1 hoặc số 2")
else:
    print("Số khác")
```

so là 5, mà Python vẫn in ra Số 1 hoặc số 2! Python đọc điều kiện thành 2 phần: `so == 1` là False, còn bên phải or chỉ là số 2, không phải 1 phép so sánh. Python hiểu số 2 là đúng, nên cả điều kiện luôn đúng, dù so là số nào.
---
Cách viết đúng: mỗi bên của or là **1 phép so sánh đầy đủ**, có tên biến, dấu so sánh và giá trị:

```python run
so = 5
if so == 1 or so == 2:
    print("Số 1 hoặc số 2")
else:
    print("Số khác")
```

Lần này Python in ra Số khác. Khi thử 1 chương trình có or, con nhớ thử cả 1 số không làm bên nào đúng, như số 5 ở đây, để chắc rằng nhánh else chạy đúng.
